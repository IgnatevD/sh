# Eliz Happy Travel — сайт гірського гіда

Сайт на React (Vite) із кількома сторінками, двома мовами (UA/EN), світлою й темною темою, анімаціями та адмінкою.

## Сторінки
- `/` — головна: альпіністи з льодорубами підіймаються на вершину, дівчинка-гід підказує, куди натиснути, далі популярні тури, сторіз, новини, галерея, відгуки та контакти
- `/tours` — усі тури з фільтрами за регіоном, складністю й місяцем
- `/tours/:slug` — сторінка туру: маршрут по днях, профіль висот, дати виїздів, бронювання
- `/calendar` — календар: обираєте дату й бачите тури, доступні в цей час
- `/news` і `/news/:slug` — новини гір (Монблан, Маттерхорн та ін.)
- `/about`, `/gallery`, `/contacts`
- `/admin` — адмінка (вхід лише за паролем)

## Адмінка
Що можна робити в адмінці:
- додавати й редагувати тури: опис, фото, ціни, маршрут, дати для календаря, статус «чернетка»
- додавати й редагувати новини
- керувати галереєю та сторіз
- міняти слайди першого екрана й усі фото сайту, а також завантажувати нові
- редагувати основні тексти та контакти (Telegram, WhatsApp, телефон, email)
- переносити фото із сайту-донора (Weblium) у власне сховище сайту (вкладка «Медіатека»)
- робити резервні копії (JSON)

Після натискання «Зберегти» зміни одразу з'являються на сайті, перезбірка не потрібна.
Дані й фото зберігаються в **Netlify Blobs** через функції з папки `netlify/functions`.

### Налаштування на Netlify (один раз)
1. У Netlify відкрийте **Site configuration → Environment variables** і додайте:
   - `ADMIN_PASSWORD` — пароль до адмінки
   - `ADMIN_SECRET` — довгий випадковий рядок (наприклад, 40+ символів)
2. Зробіть новий деплой: **Deploys → Trigger deploy**, або просто push у GitHub.
3. Відкрийте `https://ваш-сайт/admin` і увійдіть.

Налаштування збірки вже записані в `netlify.toml` (`npm run build`, папка `dist`).

## Локальний запуск
```bash
npm install
npm run dev          # сайт без адмінки (контент береться з src/data/seed.js)
npx netlify dev      # сайт разом з адмінкою та функціями (потрібен netlify-cli)
```

## Де що лежить
- `src/data/seed.js` — початковий контент: тури, новини, налаштування. Поки в адмінці нічого не збережено, сайт показує його.
- `src/data/stories.js`, `src/data/photos.js` — початкові сторіз і галерея
- `src/i18n.jsx` — усі тексти інтерфейсу UA/EN
- `src/styles.css` — стилі. Кольори задані змінними `--accent`, `--accent-2` і т.д. на початку файлу.
- `src/admin/Admin.jsx` — адмінка
- `netlify/functions/*` — API: `/api/content`, `/api/login`, `/api/upload`, `/api/img/:key`

## Важливо
- Ціни й дати нових турів (Марокко, Мадейра, Майорка, Словенія, Татри, Дурмітор, Пікос, Церматт) подані як орієнтир: ціна «за запитом», дати — сезон 2027. Уточніть їх і поправте в адмінці.
- Дати 4 оригінальних турів перенесено з програми 2024 року на 2027 рік. Їх теж треба перевірити.
- Фото Лізи поки що підвантажуються із сайту Weblium. Щоб вони не зникли, коли той сайт закриють, в адмінці відкрийте «Медіатека» → «Перенести всі у своє сховище» і натисніть «Зберегти».
- Фото нових напрямків узяті з Unsplash (ліцензія Unsplash дозволяє безкоштовне використання).
