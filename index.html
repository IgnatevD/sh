HTML5

Каркас сторінки: що і де розташовано

Кожна сторінка починається з однакового «скелета». У <head> — службова інформація, у <body> — усе, що бачить користувач.

<!DOCTYPE html>
<html lang="uk">
  <head>
    <meta charset="UTF-8">
    <title>Моя сторінка</title>
  </head>
  <body>
    <h1>Привіт!</h1>
  </body>
</html>

Семантичні теги підказують браузеру, пошуковикам і екранним читачам, яку роль виконує блок.

<header><nav><main> <section><article><aside><footer>

💡 Замість десятка <div> обирай тег, що описує зміст.

<a href="https://khai.edu">Сайт ХАІ</a>
<img src="photo.jpg" alt="Опис фото">
<ul>
  <li>Перший пункт</li>
  <li>Другий пункт</li>
</ul>

💡 Атрибут alt обов’язковий: його читають люди з вадами зору.

Форми збирають дані від користувача. Кожне поле варто підписати через <label>.

<form>
  <label for="email">Email</label>
  <input id="email" type="email" required>
  <button type="submit">Надіслати</button>
</form>

CSS3

Кольори, відступи, сітки й анімації

Селектор обирає елементи, а правила описують їхній вигляд. Якщо правила конфліктують, перемагає конкретніше або те, що написане пізніше.

p          { color: gray; }   /* тег   */
.card      { padding: 16px; } /* клас  */
#main      { width: 100%; }   /* id    */
.btn:hover { opacity: .8; }   /* стан  */

Кольори й розміри зручно тримати в одному місці. Саме так зроблено і цей сайт.

:root {
  --color-accent: #5b6cff;
  --radius: 16px;
}
.btn {
  background: var(--color-accent);
  border-radius: var(--radius);
}

Flexbox вирівнює елементи в рядок або колонку, Grid будує двовимірну сітку.

123456 
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(120px, 1fr));
  gap: 12px;
}

Спочатку пишемо стилі для телефона, а потім додаємо правила для ширших екранів. Змініть ширину вікна — цей сайт перебудується.

.cards { display: grid; gap: 12px; }

@media (min-width: 768px) {
  .cards { grid-template-columns: repeat(3, 1fr); }
}

Ефект матового скла — напівпрозорий фон плюс розмиття того, що позаду.

.glass {
  background: rgba(255, 255, 255, .45);
  backdrop-filter: blur(16px);
  border: 1px solid rgba(255, 255, 255, .6);
  box-shadow: 0 8px 32px rgba(31, 38, 135, .08);
}
JS

JavaScript

Оживлюємо сторінку

const name = 'Олена';     // рядок, не змінюється
let age = 19;             // число, можна змінити
const isStudent = true;   // логічне значення
const skills = ['HTML', 'CSS'];  // масив

💡 За замовчуванням пиши const, а let — лише коли значення справді змінюється.

function greet(name) {
  return `Привіт, ${name}!`;
}

const square = (n) => n * n;

greet('ХАІ');  // "Привіт, ХАІ!"
square(4);     // 16

DOM — це сторінка у вигляді об’єктів, які JavaScript може змінювати. Спробуйте:

const btn = document.querySelector('#counterBtn');
let count = 0;

btn.addEventListener('click', () => {
  count++;
  btn.querySelector('span').textContent = count;
});

  1. Зроби сітку з 6–9 зображень через CSS Grid.

  3. Додай плавне збільшення картинки при наведенні.
